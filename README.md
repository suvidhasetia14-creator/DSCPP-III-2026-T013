# Smart Campus Navigation System

## DSCPP-III-2026-T013

A **C++ based campus navigation system** that helps students and visitors find the shortest route between different locations on a college campus.

## Project Description

The campus is represented as a **weighted graph**:

* **Nodes** → Important campus locations
* **Edges** → Paths connecting the locations
* **Weights** → Distance between the locations

**Dijkstra's Algorithm** is used to find the shortest path between the selected starting point and destination.

## Objectives

* Help students and visitors navigate the campus easily.
* Find the shortest route between two locations.
* Apply **Graph Data Structure** to a real-world problem.
* Implement **Dijkstra's Shortest Path Algorithm** using C++.

## Technologies Used

* **Programming Language:** C++
* **Data Structure:** Graph
* **Algorithm:** Dijkstra's Algorithm
